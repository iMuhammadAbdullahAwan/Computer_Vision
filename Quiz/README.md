# Quiz Folder

Contents: notebooks and related assets for quiz exercises and reports.

Purpose
- Keep notebooks, datasets (if small), and result reports for quiz assignments.

Notebooks
- Dynamic_Slip_Cropping.ipynb — main notebook for the quiz.

How to run
1. Install required packages (example):

```powershell
pip install -r requirements.txt
```

2. Open the notebook in Jupyter or JupyterLab and run cells sequentially.

Notes
- Store any generated figures or PDF reports in a `reports/` subfolder.
- If you add datasets, place them under `cropped_slips/` or add a small README describing large-dataset locations.
